- Full CRUD capabilities for seamless data management

### [SheetMerger](https://github.com/Aaditya1111112/SheetMerge)
A desktop utility to merge multiple CSV or Excel files into one, built with Python and Tkinter.
- Merge CSV files or Excel files (.xlsx, .xls, .xlsm) separately
- Validates column count across files before merging
- Sheet picker for multi-sheet Excel files
- Tracks row origin via a `Source File` column
- [Repository](https://github.com/Aaditya1111112/SheetMerger)
